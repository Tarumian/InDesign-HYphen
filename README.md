# Adobe InDesign Հայերեն Տողադարձիչ

### ԻՆՉՊԵՍ ՏԵՂԱԴՐԵԼ WINDOWS-ՈՒՄ.

1. Փակեք Adobe InDesign-ը (եթե բաց է):
2. Երկու անգամ կտտացրեք **`install.bat`** նիշքի վրա:
3. Թույլատրեք Վարիչի հարցումը (UAC -> Yes):
4. Տեղադրիչը ինքնաբար կտեղադրի հայերեն տողադարձման բառարանը:

\---

### ԻՆՉՊԵՍ ՏԵՂԱԴՐԵԼ MacOS-ՈՒՄ.

1. Փակեք Adobe InDesign-ը (եթե բաց է):
2. Երկու անգամ կտտացրեք **`install\_mac.command`** նիշքի վրա (կամ բացեք Terminal-ում):
3. Բացվող Terminal պատուհանում մուտքագրեք ձեր Mac-ի գաղտնաբառը եւ սեղմեք Enter:
4. Տեղադրիչը ինքնաբար կգտնի InDesign-ը եւ կտեղադրի բառարանը:

*(Նշում. եթե MacOS-ը նախազգուշացում տա նիշքը բացելու վերաբերյալ՝ աջ կտտոց `install\_mac.command` -> Open / Բացել)*:

\---

### ԻՆՉՊԵՍ ՕԳՏԱԳՈՐԾԵԼ INDESIGN-ՈՒՄ.

1. Բացեք Adobe InDesign-ը:
2. Գնացեք **Edit -> Preferences -> Dictionary** (macOS-ում՝ **InDesign -> Settings/Preferences -> Dictionary**):
3. **Language** ցանկից ընտրեք **«Armenian»** (կամ *«Armenian (Armenia)»*):
4. **Hyphenation** բաժնում ստուգեք, որ ընտրված լինի **«Hunspell»**:
5. Գրվածքը նշեք, **Character** վահանակում լեզուն դրեք **«Armenian»**, իսկ **Paragraph** վահանակում միացրեք **«Hyphenate»** նշիչը:

\---

### ՀԵՌԱՑՆԵԼՈՒ ՀԱՄԱՐ.

* **Windows**՝ Աշխատեցրեք **`uninstall.bat`** նիշքը:
* **macOS**՝ Աշխատեցրեք **`uninstall\_mac.command`** նիշքը:
